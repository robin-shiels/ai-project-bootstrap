# S02: Inventar und Wiederherstellung

Paraphrase des lokalen Inventars, kein Originalexport. Sieben persönliche Skillquellen liegen in einer gesicherten Ablage; die lokale Codex-Discovery nutzt Verknüpfungen. Weitere eigene Skills liegen in anderen Projekt- oder Skillordnern. Die zehn in diesem Beitrag untersuchten eigenen Skills sind im aktuellen Gesprächskatalog sichtbar.

Eine weitere Maschine oder Laufzeit erhält dadurch keine automatische Kopie. Python-/Office-/OCR-Werkzeuge brauchen eine eigene Installation. Die deklarierte Werkzeugverfügbarkeit im Skill muss auf dem Zielsystem geprüft werden. Das hier erfasste Inventar ist keine Behauptung über erfolgte Ausführung aller Skills.
